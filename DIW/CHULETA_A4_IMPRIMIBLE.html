Parte 3 · Teoría
12. Conceptos clave (S01)
IPO: Interacción Persona-Ordenador (disciplina)
Usabilidad: facilidad de uso, rapidez y satisfacción
Accesibilidad: acceso para cualquier usuario (WCAG)
POUR: Perceptible (se ve/oye) | Operable (teclado/ratón)
 Understandable (comprensible) | Robust (navegadores)
 Niveles de conformidad: A, AA, AAA (máximo)
Breadcrumbs: migas de pan (<nav aria-label="Ruta">)
Tooltip: mensaje emergente al hacer hover
Carousel: carrusel deslizable de fotos/tarjetas
Tabs: pestañas de contenido intercambiable
Modal/Popup: ventana emergente superpuesta
Spinner: indicador circular animado de carga
Card: tarjeta con imagen, título y texto
Banner: franja destacada (cookies / aviso / hero)
Action Bar: barra flotante con botones de acción
13. Selectores, pesos y pseudo-clases (S05-06)
h1, h2    /* COMA: agrupa */
div p     /* ESPACIO: descendiente (cualquier nivel) */
div > p   /* MAYOR: hijo directo */
h2 + p    /* MÁS: hermano adyacente (el p justo detrás) */
h2 ~ p    /* VIRGULILLA: todos los p hermanos detrás */
/* PESOS: el más específico gana */
*  = 0 | div = 1 | .clase = 10 | div.clase = 11
#id = 100 | style="" = 1000 | !important = gana siempre
/* empate: gana el que está más abajo */
input[type="text"]  /* exacto */
input[name^="txt"]  /* empieza por */
input[name$="id"]   /* termina en */
input[name*="val"]  /* contiene */
:first-child | :last-child | :nth-child(even|odd)
a:hover (ratón encima) | a:active (click) | input:focus
h1::before { content: "★ "; }  h1::after { content: " ↗"; }
:not(.activo) | :is(h1,h2) | :has(img)
14. Unidades y funciones CSS3 (S07-08)
rem = relativo a la raíz :root/html (16px).
em  = relativo al font-size del PADRE (cascada).
vmin = 1% del menor entre ancho y alto del dispositivo.
width: calc(100% - 2rem);
font-size: clamp(1rem, 2.5vw, 1.8rem);  /* min, ideal, max */
background: color-mix(in srgb, var(--color1) 70%, white 30%);
