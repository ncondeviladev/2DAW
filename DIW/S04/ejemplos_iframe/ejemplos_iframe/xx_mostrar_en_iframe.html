Página para mostrar dentro de 01_main_iframe

Esta página tiene Scripts, Forms, Alerts..
Con ella comprobamos si el atributo sandbox funciona o no.

Si en el iframe donde se muestro tenemos el atributo sandbox, veremos que no se ha ejecutado el script de abajo, ni se puede enviar el Form cuando pulso enviar...

Si en el iframe donde se muestro quito sandbox, veremos que sí se ejecuta script, y sí se envian datos del Form...
