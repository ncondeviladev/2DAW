nav a, .btn {

5. Tablas: Los 3 Patrones de Examen
[HTML] 
1. Encabezados arriba (scope="col")
<table>
  <thead>
    <tr><th scope="col">Columna 1</th><th scope="col">Columna 2</th></tr>
  </thead>
  <tbody>
    <tr><td>Dato A</td><td>Dato B</td></tr>
  </tbody>
</table>

2. Ficha técnica (th a la izquierda en cada fila)
<table>
  <tbody>
    <tr><th scope="row">Campo 1</th><td>Valor 1</td></tr>
    <tr><th scope="row">Campo 2</th><td>Valor 2</td></tr>
  </tbody>
</table>

3. Fusiones (colspan, rowspan y enlaces)
<table>
  <thead>
    <tr><th colspan="2">Título General (2 columnas)</th></tr>
  </thead>
  <tbody>
    <tr>
      <th rowspan="2" scope="row">Contacto</th>
      <td><a href="tel:600000000">Tel: 600 000 000</a></td>
    </tr>
    <tr>
      <!-- aquí NO va <th>, lo ocupa rowspan desde arriba -->
      <td><a href="mailto:info@ej.com">info@ej.com</a></td>
    </tr>
  </tbody>
</table>
[CSS] 
table { width: 100%; border-collapse: collapse; }
/* Selector específico para evitar fallos por coma: */
article table th, article table td {
  border: 1px dotted var(--color1); padding: 0.3em 0.6em;
}
tbody tr:nth-child(even) { background-color: #f8fafc; }
tbody tr:hover           { background-color: #f1f5f9; }

10. Árbol y Maquetación con Flexbox
[CSS] 
/* 1. ACTIVADOR OBLIGATORIO (en el padre): */
display: flex; /* ¡SIN ESTO NADA DE ABAJO FUNCIONA! */

/* 2. PROPIEDADES DEL PADRE (CONTENEDOR): */
flex-direction: row | row-reverse | column | column-reverse;
flex-wrap: nowrap | wrap | wrap-reverse;
flex-flow: row wrap; /* atajo: dirección + wrap */
/* Eje principal (X en row / Y en col): */
justify-content: flex-start | flex-end | center | space-between | space-around | space-evenly;
/* Eje secundario (1 sola fila): */
align-items: flex-start | flex-end | center | stretch | baseline;
/* Eje secundario (varias filas con wrap): */
align-content: flex-start | flex-end | center | space-between | stretch;
gap: 1rem; /* separación entre hijos */

/* 3. PROPIEDADES DE LOS HIJOS (ITEMS INDIVIDUALES): */
order: -1 | 0 | 1; /* orden visual (menor sale antes) */
align-self: auto | flex-start | flex-end | center | stretch;
flex: 1 1 250px; /* grow shrink basis */

LAS 2 RECETAS CLÁSICAS DE MAQUETACIÓN:
/* A) Rejilla de tarjetas que saltan si no caben (wrap): */
#contenedor { display: flex; flex-flow: row wrap; justify-content: space-around; }
.tarjeta    { width: 30%; min-width: 250px; } /* en móvil salta */

/* B) Layout 2 columnas (móvil 1 col, PC 2 cols): */
@media (min-width: 768px) {
  .layout  { display: flex; flex-direction: row; }
  .col-ppal { flex: 0 0 70%; }  .col-lat { flex: 0 0 25%; }
}
11. CSS Base y Teoría de Examen (20 Min)
@charset "utf-8";
@import url('url-google-fonts');
@font-face {
  font-family: 'FuenteLocal';
  src: url("../assets/fuente.ttf") format('truetype');
}
*, *::before, *::after { margin: 0; padding: 0; box-sizing: border-box; }
:root {
  --color1: #0f172a; --color2: #334155; --color3: #64748b;
  font-family: Arial, sans-serif; font-size: 16px;
}
/* Centrar body o caja en pantalla: */
width: 90%; margin: 0 auto 2rem auto;

ESCALERA DE PESOS (ESPECIFICIDAD DE SELECTORES):
* = 0 | tag = 1 | .clase = 10 | tag.clase = 11 | #id = 100 | style = 1000 | !important
/* Empate a peso: gana el que esté escrito MÁS ABAJO en el CSS */

COMBINADORES:
div p (descendiente) | div > p (hijo directo) | h2 + p (hermano adyacente) | h2 ~ p (general)

SELECTORES ATRIBUTO: [attr="val"] (exacto) | [attr^="ini"] (empieza) | [attr$="fin"] (termina) | [attr*="sub"] (contiene) | :not(.clase)

:PSEUDOCLASES (ESTADO) vs ::PSEUDOELEMENTOS (PARTE VIRTUAL):
:hover (ratón) | :active (clic) | :focus (cursor) | :checked | :nth-child(even|odd|n)
::before / ::after (content:"") | ::placeholder | ::first-letter

CONCEPTOS UI Y FUNCIONES:
IPO: Interacc. Persona-Ordenador | Usabilidad: Facilidad, rapidez | Tooltip: Flotante | Breadcrumbs: Miga pan
calc(100% - 40px) (espacios en + -) | color-mix(in srgb, red 40%, blue 60%) | transform: translate(x,y) rotate(deg) scale(n)
rem vs em: rem es relativo a raíz :root (16px fijos); em es relativo al padre (cascada).
