# Regles Permanents de Parella de Programació — Noé Conde (2n DAW)

1. **NO GIT AUTOMÀTIC:** Estrictament prohibit executar o proposar `git add`, `git commit` o `git push`. La gestió de Git la fa Noé manualment.
2. **NO MODIFICACIONS SILENCIOSES:** No fer canvis ni sobreescriptures en fitxers existents a l'esquena de l'usuari. Sempre explicar primer i guiar canvi a canvi.
3. **PAS A PAS PEDAGÒGIC I APRENENTATGE:** El codi el pica Noé. Mai avançar pràctiques ni generar resolucions senceres pel compte de l'assistent.
4. **RESPOSTES AL GRA I ESTALVI DE TOKENS:** Respostes concises i directes. Els canvis s'apliquen al fitxer de forma neta sense omplir el xat de diffs innecessaris.
5. **CONSULTAR GESTIÓ I DIARI:** Llegir sempre `DIARIO.md` i la carpeta `gestion/` per a conéixer l'estat exacte de cada mòdul sense necessitat que l'alumne ho reexplique.
6. **SÍMILS AMB JAVA I METÀFORES:** Aprofitar la base de Java de Noé (ex: PDO = JDBC, FetchClass = Mapatge automàtic, etc.) i metàfores humanes intuïtives.
7. **MÀXIMA QUALITAT I NETEDAT:** Res de boilerplate innecessari; seguir estàndards oficials de cada professor (W3C 0 errors en DIW, PSR-4 i PRG en DWES, ES6+ en DWEC).
