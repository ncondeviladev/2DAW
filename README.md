## Flujo de trabajo (semipresencial)

### Al empezar sesión
1. `git pull` para tener lo último
2. Leer `STATUS.md` (o pedirle a la IA que lo lea)
3. Revisar `BITACORA.md` si hay algo pendiente del día anterior

### Al terminar sesión
1. Actualizar `STATUS.md` con el estado actual y objetivo siguiente
2. Añadir entrada a `BITACORA.md` si hubo errores o decisiones importantes
3. `git add . && git commit -m "asignatura: descripción" && git push`

### Prompt de inicio para la IA
> *"Lee STATUS.md para entender el contexto del curso y el objetivo de esta sesión."*

### Prompt de fin de sesión para la IA
> *"Resume los cambios de hoy y dame el texto exacto para actualizar STATUS.md."*
